# DevDash AI

AI-Powered Productivity Dashboard built with Flask, MySQL and Gemini AI.

## Features

- User Authentication
- Goal Management
- Resource Management
- Profile Management
- Settings Management
- Gemini AI Coding Assistant
- Responsive Dashboard UI

## Tech Stack

- Flask
- MySQL
- SQLAlchemy
- JavaScript
- HTML/CSS
- Gemini AI API

## Installation

```bash
pip install -r requirements.txt
python run.py
```
